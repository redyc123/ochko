# OCHKO — три направления интерфейса

Три концепта редизайна приложения: карта, голосовой ассистент и экран очков.
Каждый вариант — три экрана в одном характере. Это статические макеты, не код приложения.

## Что смотреть

- `overview.png` — все девять экранов на одном листе для сравнения.
- `v1/`, `v2/`, `v3/` — по три PNG: `01-navigation`, `02-assistant`, `03-device`.
- Рядом с каждым PNG лежит HTML/CSS-исходник. Его можно открыть в браузере и править.

Размер макета — 390 × 844 (iPhone 14/15), PNG отрендерены в 3× (1170 × 2532).

## Варианты

| | V1 · Air | V2 · Pulse | V3 · Terra |
|---|---|---|---|
| Настроение | светлое, спокойное, точное | тёмный HUD, спортивное | тёплое, редакционное |
| Палитра | тёплый белый, изумруд, песок | почти чёрный, лайм, циан | крем, терракота, шалфей |
| Шрифт | системный | системный, капс | антиква в заголовках |
| Кому | ежедневный инструмент | улица, ночь, техника | характер и «человечность» |

### V1 · Air

Максимум воздуха и читаемости. Светлая карта, белая поисковая пилюля, изумрудный маршрут.
Нижний лист с крупным манёвром «850 м», временем и расстоянием. Очки показаны маленькой
живой карточкой, а не отдельным тяжёлым блоком.

### V2 · Pulse

Тёмная карта с светящимся лаймовым маршрутом. Крупные капсовые подписи, лаймовый манёвр,
жёсткая кнопка «СТАРТ». Ассистент — тёмный чат с лаймовой подсветкой реплик.
Экран очков — радар, сегментированная батарея и ощущение пульта управления.

### V3 · Terra

Тёплая бумажная фактура, терракота и антиква. Приветствие «Добрый день», карта как
путевой лист, полароид с очками. Крупная типографика «12 мин / 1.4 км», кнопка «В путь».
Самый авторский вариант, дальше всех от «стандартного навигатора».

## Что общего у всех трёх

- Постоянный нижний таб-бар **Карта / Ассистент / Очки** вместо ссылок в шапке.
- Следующий манёвр — главный элемент экрана навигации, а не строка в списке.
- Компактный live-превью очков: видно, что на них сейчас, без перехода на отдельный экран.
- Ассистент — voice-first: большая кнопка микрофона, быстрые действия, чат как лента.
- Экран очков — статус-дашборд: подключение, батарея, прошивка, протокол, симуляция.

## Как перерендерить

Один экран:

```bash
"/Applications/Google Chrome.app/Contents/MacOS/Google Chrome" \
  --headless=new --disable-gpu --hide-scrollbars \
  --force-device-scale-factor=3 --window-size=390,844 \
  --screenshot="$PWD/references/v1/01-navigation.png" \
  "file://$PWD/references/v1/01-navigation.html"
```

Общий лист:

```bash
"/Applications/Google Chrome.app/Contents/MacOS/Google Chrome" \
  --headless=new --disable-gpu --hide-scrollbars \
  --force-device-scale-factor=1 --window-size=1240,2360 \
  --screenshot="$PWD/references/overview.png" \
  "file://$PWD/references/overview.html"
```

## Важно

- Карты — стилизованный inline SVG, а не реальные геоданные. Для макета этого достаточно;
  в приложении остаётся `react-native-maps`.
- Тексты — настоящие русские формулировки интерфейса, не lorem ipsum.
- HTML/CSS — источник макета, а не продакшн-код. Переносить в React Native нужно паттерны
  и состояния, а не разметку один-в-один.
